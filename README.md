
Contact management system using python 3

About the Project

This is a simple Contact Management System made using Python. It helps us save and manage contact details like name, phone number, and email.

Features

- Add a new contact.
- View all contacts.
- Search a contact by name.
- Update contact details.
- Delete a contact.
- Check phone number length.
- Prevent duplicate phone numbers.

Language Used

- Python 3

Concepts Used

- Lists
- Dictionaries
- Functions
- Loops
- If-Else
- CRUD Operations

How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run the Python file.

Objective

The main purpose of this project is to learn Python and understand how to add, search, update, and delete contact details.
